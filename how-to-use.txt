==================================================
        NOOR UL QURAN - HOW TO USE GUIDE
==================================================

--------------------------------------------------
STEP 1: INITIAL SETUP & ASSETS
--------------------------------------------------

1. Requirements Install Karein:
   pip install -r requirements.txt

2. Assets Fetch Karein:
   Quran Majeed ka Arabic Uthmani text aur Urdu translation download karne ke liye:
   python fetch_assets.py

3. Fonts Aur Backgrounds Add Karein:
   - Urdu/Arabic Font: fonts/ folder mein official Quranic font (maslan Amiri-Regular.ttf ya ScheherazadeNew-Regular.ttf) daalein.
   - Background Videos: 1080x1920 (Vertical) HD videos (Pexels / Pixabay se) backgrounds/ folder mein daalein.
  - (Optional) Frame Overlay: Apna transparent PNG design public/assets/overlay.png mein rakh sakte hain.


--------------------------------------------------
LOCAL WEBSITE SERVER START / STOP (WINDOWS)
--------------------------------------------------

1. Project folder VS Code mein kholein aur Terminal > New Terminal chunein.
2. Agar terminal project folder mein nahi hai to chalaein:
  cd "C:\Users\Panda Gaming Store\OneDrive\Desktop\Noor-ul-Quran"
3. Local server start karne ke liye:
  .\venv\Scripts\python -m uvicorn main:app --host 127.0.0.1 --port 8000
4. Browser mein yeh address kholein:
  http://127.0.0.1:8000
5. Server ko band karne ke liye usi terminal mein Ctrl+C dabayein.

Server chalte waqt usi port par doosra server start na karein. Agar "only one usage of each socket address" error aaye to port 8000 pehle se use ho raha hai. Pehle purane server wale terminal par ja kar Ctrl+C karein; agar woh terminal mil nahi raha to pehle check karein ke http://127.0.0.1:8000/api/health open ho raha hai ya nahi. Unknown process ko force stop na karein.

Har dafa reels banane ke liye website/server chalna zaroori hai; terminal band karne par local server band ho jata hai. Browser session pehle se khula ho to page refresh karein.


--------------------------------------------------
STEP 2: VIDEOS GENERATE KARNE KI COMMANDS
--------------------------------------------------

Option A: Direct Kisi Ek Specific Verse Ki Video Banani Ho (Fastest)
------------------------------------------------------------------
Puri picks.txt ko edit kiye bina, terminal se direct ek Surah ya Verse ki video banane ke liye:

- Choti Reel (Single Verse):
  python make.py --pick 55:1-8

- Lambi Video / Waqia (Up to 1m 30s):
  python make.py --pick 18:9-15 --max-dur 90


Option B: Multiple Selected Ayaat Se Videos Banani Ho (picks.txt)
------------------------------------------------------------------
picks.txt file kholein aur apni pasand ki ayaat likhein:

# Jis line ke shuru mein # hoga wo skip ho jayegi
55:1-8
2:284-286
18:9-15

Terminal par Command chalaein:
python make.py --picks picks.txt


Option C: Automatic Random Reels Banani Ho (Auto Pilot)
-------------------------------------------------------
- 1 Random Video (Standard 20-60 Seconds):
  python make.py --random 1

- 5 Random Videos Ek Sath:
  python make.py --random 5

- 1 Random Long Video (1 to 1.5 Minutes):
  python make.py --random 1 --max-dur 90


--------------------------------------------------
HELPFUL COMMANDS & CHECKS
--------------------------------------------------

- Audio Check Karein:
  Yeh check karne ke liye ke kisi Surah ki audio server par available hai ya nahi:
  python make.py --check 112 55 18

- Dry Run (Testing Without Video Generation):
  Video generate kiye bina sirf plan check karne ke liye:
  python make.py --picks picks.txt --dry


--------------------------------------------------
OUTPUT LOCATIONS
--------------------------------------------------

- Tayar Videos: output/ folder mein .mp4 format mein save hoti hain.
- Video Captions: output/captions.csv file mein har video ka Title, Ayat details, aur Hashtags mil jayenge.


--------------------------------------------------
AUDIO & QARI CUSTOMIZATION (make.py Settings)
--------------------------------------------------

make.py file ke top par aap yeh settings change kar sakte hain:

- Arabic Reciter: ARABIC_FOLDER = "Alafasy_128kbps" (EveryAyah.com se doosre Qari ka folder name bhi rakh sakte hain).
- Urdu Reciter: URDU_FOLDER = "translations/urdu_shamshad_ali_khan_46kbps"
- Sirf Urdu Audio (No Arabic): INCLUDE_ARABIC_AUDIO = False
- Video Brightness: BRIGHTNESS = -0.18 (Dark background ke liye).


--------------------------------------------------
ZAROORI HIDAYAT
--------------------------------------------------

1. Pehli 5 videos ko upload karne se pehle zaroor sunein taake audio aur Urdu text ki sync check ho sake.
2. Render time video ki length aur computer par depend karta hai. Pehli dafa audio download hone ki wajah se extra waqt lag sakta hai. Supported GPU encoder available ho to use hota hai; warna faster CPU encoding chalta hai. Render mukammal hone tak terminal ko stop na karein (Ctrl+C na dabayein).
3. Reel ke dauran backgrounds randomly change karne ke liye backgrounds/ mein kam az kam 2 alag videos rakhein. Har clip ke khatam hone par doosri clip aati hai; agar sirf 1 unique clip ho to usi ko repeat karna padega.


--------------------------------------------------
USER LOGIN & ADMIN ACCESS (ONE-TIME SETUP)
--------------------------------------------------

1. Supabase Dashboard mein apna project kholein aur SQL Editor par jaein.
2. Pehle Supabase Dashboard > Authentication > Users se apni user UUID copy karein. schema.sql mein <YOUR_ADMIN_USER_ID> ko us UUID se replace karein, phir poora SQL Supabase SQL Editor mein paste karke Run karein. Is se secure role tables/RPCs banenge aur aapke account ko admin access milega.
3. Local project .env mein SUPABASE_URL aur SUPABASE_ANON_KEY set karein; values Supabase Project Settings > API se lein. Service-role key kabhi browser ya .env ke SUPABASE_ANON_KEY mein na daalein.
4. Uvicorn server restart karke /auth.html par sign in karein. Admin account ko Admin Portal dikhai dega.
5. Admin Portal mein registered user ke Premium checkbox se bulk/custom/random access grant ya revoke karein.

Naye users email confirmation ke baad sign in karenge. Free users single-pick mode use kar sakte hain; premium access custom list, random reels aur 60 seconds se lambi videos unlock karta hai.

--------------------------------------------------
ADMIN: BACKGROUND, TEXT & AUDIO ADD KARNA
--------------------------------------------------

1. Admin account se sign in karke Admin Portal kholein.
2. "Background clips" mein MP4/MOV video upload karein (50 MB maximum).
3. "Urdu / Arabic text and audio" mein Surah number aur Ayah number select karke Load verse dabayein.
4. Arabic text aur Urdu tarjuma update karke Save text dabayein. Khali text ka matlab Quran data ka default text use hoga.
5. Arabic recitation ya Urdu translation audio select karein, MP3/M4A/AAC/WAV file choose karein, phir Upload audio dabayein (50 MB maximum).
6. Nayi reel banate waqt custom text/audio usi Surah:Ayah par use honge; jahan custom audio upload nahi ki, wahan default EveryAyah audio use hogi.

Local use mein custom text/audio data/admin_content.json aur audio/admin/ mein save hota hai. Hosted Render deployment mein private Supabase Storage persistence ke liye schema.sql dobara run karein; service-role key sirf backend host ke environment mein honi chahiye.
